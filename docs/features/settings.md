### <u>⚙️ Settings Suite</u>

[← Back to main README](../../README.md)

The Settings Suite provides a complete set of user configuration options, reflecting the deep customization available in a modern 2026 application.

### <u>Configuration Modules</u>

- **Linked Devices:** Interface for managing and authenticating multi-device sessions securely.
- **Privacy Controls:** Granular privacy configurations including Last Seen, Profile Photo visibility, Status privacy, and Chat Locks.
- **Appearance & Theming:** 
  - Dynamic **Dark and Light mode** toggles.
  - Interactive chat **color pickers** and **wallpaper grids** for ultimate chat personalization.
- **Account & Security:** Two-step verification, passkey management, email integration, and secure account deletion protocols.
- **Storage & Data:** Mock interfaces for storage management, network usage metrics, and media auto-download preferences.

Settings are deeply integrated with the app's `localStorage` and Redux stores, ensuring immediate global UI updates upon any configuration change.
