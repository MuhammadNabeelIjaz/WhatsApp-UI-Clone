### <u>📞 Calls Architecture</u>

[← Back to main README](../../README.md)

The Calls module delivers a comprehensive VoIP-style interface simulation, featuring seamless integrations for both audio and video call layouts.

### <u>Core Functionality</u>

- **Call History & Favorites:** A robust call log system integrated with a Favorites manager for quick access to frequent contacts.
- **Interactive Dialer:** A fully functional, smooth-animated dial pad for initiating new calls.
- **Active Call Interface:** A sleek, 2026-styled active call screen supporting responsive grid layouts for multi-participant video and voice calls.
- **Advanced Scheduling:** 
  - Schedule upcoming calls via integrated Date and Time picker modals.
  - Generate and share secure **Call Links** for effortless group assembly.

The interface is completely modularized, utilizing Redux state slices for call statuses to ensure a fluid and uninterrupted user experience.
