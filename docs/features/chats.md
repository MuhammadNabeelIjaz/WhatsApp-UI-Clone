### <u>💬 Chats Architecture</u>

[← Back to main README](../../README.md)

The Chats module forms the core of the WhatsApp UI Clone, offering a highly responsive and feature-rich messaging interface powered by **React 19** and **Redux Toolkit**.

### <u>Core Capabilities</u>

- **Rich Message Ecosystem:** Full support for diverse message types including text, rich media (images/videos), voice notes, interactive location sharing, contact cards, polls, and event invitations.
- **Advanced Interactions:** Seamless reply threads, swipe-to-reply gestures, and emoji reactions designed to mirror the 2026 WhatsApp standards.
- **State Management & Selection:** Implement multi-select modes for bulk operations—allowing users to efficiently forward, delete, star, or pin multiple messages.
- **Categorization & Filters:**
  - Separate views for **Starred** and **Kept** messages.
  - Native support for **Custom Lists** to categorize chats dynamically.
  - Secure **Locked Chat** environments and **Archive** views.
- **Real-time Search:** Highly optimized in-chat and global sidebar search with localized filtering.

> **Note:** The underlying state is strictly typed and managed via Redux slices, ensuring a scalable foundation for real-time WebSocket integrations.
