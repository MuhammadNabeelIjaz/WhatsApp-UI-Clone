### <u>🧩 Platform & Core Integrations</u>

[← Back to main README](../../README.md)

The Platform module handles the foundational infrastructure and global utilities of the WhatsApp UI Clone, ensuring an accessible, localized, and highly performant application.

### <u>Global Capabilities</u>

- **Internationalization (i18n):** Native multi-language support (English, Arabic, German, Spanish, French, Urdu) with full **RTL (Right-to-Left)** layout inversion.
- **Progressive Web App (PWA):** Built-in PWA compliance. The application is installable on desktop and mobile platforms via Service Workers and a complete Web App Manifest.
- **Advanced Theming:** A highly scalable Tailwind CSS 4 configuration paired with CSS variables for instantaneous global theme switching.
- **Virtualization:** Rendering optimization using **TanStack Virtual**, ensuring 60FPS scrolling performance even with thousands of local mock messages and contacts.
- **Notification System:** A globally accessible, animated Toast and notification service for providing immediate user feedback.

This layer ensures the application remains highly scalable and provides an authentic, app-like experience within the browser.
